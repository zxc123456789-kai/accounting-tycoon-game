# Accounting Tycoon｜會計小店長

以 Phaser 3.90 製作的高職會計分錄練習遊戲。遊戲使用 Phaser 的 Graphics API 繪製商店和互動元件，不需要額外圖檔。

## GitHub Pages

- [Accounting Tycoon](https://zxc123456789-kai.github.io/accounting-tycoon-game/)
- [機制 04 會計知識王](https://zxc123456789-kai.github.io/accounting-tycoon-game/game-learning.html)

## 開始遊玩

用瀏覽器開啟 `index.html`。頁面會從 cdnjs 載入 Phaser 3.90，因此遊玩時需要網路連線。

## 遊戲內容

- 現金進貨、賒購補貨、銷售商品和支付店租。
- 儀表板顯示現金、商品總庫存、累計銷貨與應付帳款。
- 三道會計分錄選擇題：賒購商品、支付租金、業主投資。
- 答題後顯示正確分錄、科目增減說明和學習積分。
